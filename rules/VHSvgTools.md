# VHSvgTools

## Файл / Модуль

- Заголовок: `src/mods/svgtools/svgtools.hpp`
- Реализация: `src/mods/svgtools/svgtools.cpp`
- Класс: `class VHSvgTools`

## Назначение

Первопартийные (не submodule) помощники для безопасного вывода SVG:
экранирование текста для XML и сохранение документа с проверкой
результата. Обёртка компенсирует то, что `VHSVG::savetosvg()` из
submodule `vhlibsvg` возвращает `void` и не сообщает об ошибках записи.

## Ответственность

- Экранирование пользовательских строк перед вставкой в XML.
- Сохранение готового `VHSVG` в файл.
- Проверка, что файл создан, непустой и содержит закрывающий тег `</svg>`.

## Методы

| Сигнатура | Описание |
|---|---|
| `static std::string EscapeXml(const std::string &text)` | Заменяет `&`, `<`, `>`, `"`, `'` на `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`. Управляющие символы `< 0x20`, кроме `\t`, `\n`, `\r`, заменяет на `?`. |
| `static verr Save(VHSVG &svg, const std::string &fname)` | Сначала открывает целевой файл на запись/усечение (проверка прав и занятости пути), затем вызывает `svg.savetosvg(fname)`, после чего проверяет размер и хвост файла. Возвращает `vok` при успехе; коды `1..5` — файл нельзя создать, он пуст, не читается, не содержит `</svg>` или содержит данные после закрывающего тега. |

## Связи / Зависимости

- **Входящие:** `VHDocWnd::GenerateDocument()`, `VHDocDNA::GenerateDocument()`.
- **Исходящие:** `VHSVG` (submodule `vhlibsvg`), `std::ofstream`/`std::ifstream`, `vhplatform` (`verr`/`vok`).

## Использование

```cpp
svg.end();
const verr r = VHSvgTools::Save(svg, fnamewnd);
if (vok != r)
    return verrmsg(6, "Error generating docwnd");

const std::string safe = VHSvgTools::EscapeXml(sourceFileName);
svg.text(x, y, safe, "Arial", 16, color);
```

## Ограничения / Замечания

- Проверка записи выполняется **после** `VHSVG::savetosvg()`: библиотека
  всё равно печатает собственное сообщение `Data successfully saved ...`
  до того, как `VHSvgTools::Save` обнаружит усечение или ошибку.
- Проверяется только наличие закрывающего `</svg>` в хвосте файла, а не
  полная XML-валидность и не корректность всех атрибутов.
- `EscapeXml` не проверяет UTF-8: предполагается, что входная строка уже
  является корректным UTF-8 (типично для имён файлов в POSIX).
- Предварительное усечение целевого файла означает, что при неудачной
  записи старый документ не сохраняется.
