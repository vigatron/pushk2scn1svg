# VHKeyFingerPrint

## Файл / Модуль

- Заголовок: `src/mods/widerange/vhkeyfingerprint.hpp`
- Реализация: `src/mods/widerange/vhkeyfingerprint.cpp`
- Класс: `class VHKeyFingerPrint`

## Назначение

Битовый отпечаток (фингерпринт) позиций одного значения байта внутри
сканируемого массива. Хранит битовый массив размером `MAX_RANGE` бит,
абсолютные границы вхождений (`startpos`/`endpos`) и выбранное
координатное пространство. Используется внутри `VHWideRangeScan`
для каждого из 256 значений.

## Ответственность

- Отметка позиций вхождения символа в выбранном координатном пространстве.
- Проверка установленного бита по позиции в том же пространстве.
- Хранение первой и последней абсолютной позиции вхождения.
- Хранение признака относительного пространства (`relmode`).
- Дамп содержимого в stdout.

## Координатные пространства

| Режим | Что хранится в битовом массиве | Как заполняется |
|---|---|---|
| Абсолютный | Абсолютные позиции `0..MAX_RANGE-1` от начала буфера. | `putabs(pos)` — помечает `pos` при каждом вызове, включая первое вхождение. |
| Относительный | Смещения `pos - startpos` от первого вхождения значения. | `putrel(pos)` — при первом вызове помечает `0`, далее `pos - startpos`. |

`startpos` и `endpos` всегда хранят **абсолютные** позиции первого и
последнего вхождения, независимо от режима. Пространство фиксируется первым
вызовом `putabs`/`putrel` и доступно через `isRelative()`. Потребитель
обязан опрашивать `status()` в том же пространстве, в котором заполнялся
отпечаток.

## Поля / Данные

| Поле | Тип | Назначение |
|---|---|---|
| `MAX_RANGE` | `static const size_t = 32 * F1K` (32 КБ / 32 768 байт) | Максимальный размер сканируемого массива (в позициях). |
| `avail` | `bool` | Флаг: было ли хотя бы одно вхождение. Инициализируется `false`. |
| `relmode` | `bool` | Флаг: битовый массив хранит относительные смещения. Инициализируется `false`. |
| `startpos` | `uint16_t` | Абсолютная позиция первого вхождения; `0` до первого вызова. |
| `endpos` | `uint16_t` | Абсолютная позиция последнего вхождения; `0` до первого вызова. |
| `arr` | `std::vector<uint8_t>` | Битовый массив (`MAX_RANGE/8 = 4096` байт, инициализируется нулями). |

## Методы

| Сигнатура | Описание |
|---|---|
| `VHKeyFingerPrint()` | Инициализирует `avail=false`, `relmode=false`, `startpos=0`, `endpos=0`, выделяет обнулённый битовый массив. |
| `void putabs(uint16_t pos)` | Регистрирует абсолютную позицию `pos`: обновляет `startpos`/`endpos`, помечает бит `pos`. Первое вхождение помечается наравне с остальными. |
| `void putrel(uint16_t pos)` | Регистрирует вхождение по абсолютной позиции `pos`: при первом вызове задаёт `startpos` и помечает бит `0`; далее помечает `pos - startpos`. `endpos` обновляется по абсолютной позиции. |
| `void mark(uint16_t pos)` | Устанавливает бит `pos` через `VHBits::BitSet(arr.data(), pos)`. |
| `bool status(uint16_t pos) const` | Возвращает значение бита `pos` через `VHBits::BitVal(arr.data(), pos)`. |
| `bool valid() const` | `return avail;` |
| `bool empty() const` | `return !avail;` |
| `uint16_t getStartPos() const` | Возвращает абсолютную позицию первого вхождения. |
| `uint16_t getEndPos() const` | Возвращает абсолютную позицию последнего вхождения. |
| `uint16_t getSpan() const` | Возвращает `endpos - startpos` — ширину относительного диапазона. |
| `bool isRelative() const` | Возвращает `relmode`. |
| `void dump() const` | Печатает диапазон `[S E]` и все установленные позиции; в относительном режиме перебирает `0..getSpan()`, в абсолютном — `startpos..endpos`. |

## Связи / Зависимости

- **Входящие:** `VHWideRangeScan` (хранит 256 объектов), `VHDocDNA::Gen256Stat()` (читает `status()`, `getStartPos()`, `getEndPos()`, `getSpan()`, `empty()` и режим скана для отрисовки).
- **Исходящие:** `VHBits` (submodule `vhlibplatform`) — битовые операции; `vhplatform` (`F1K`).

## Использование

```cpp
VHKeyFingerPrint fp;
fp.putabs(0);
fp.putabs(5);
bool present = fp.status(5);  // true

VHKeyFingerPrint rel;
rel.putrel(10);
rel.putrel(14);
rel.status(0);   // true (первое вхождение)
rel.status(4);   // true (смещение 14 - 10)
```

## Ограничения / Замечания

- Смешивать `putabs` и `putrel` на одном объекте нельзя: режим фиксируется
  первым вызовом, последующие вызовы другого типа дадут несогласованные
  координаты.
- `putabs`/`putrel` принимают `uint16_t pos` — при размере массива > 65535
  была бы обрезка, но `VHWideRangeScan` ограничивает сканирование `MAX_RANGE`.
- Память: 4096 байт на объект; 256 объектов в одном сканировании — ~1 МБ.
- Повторное сканирование тем же объектом `VHWideRangeScan` не очищает
  отпечатки (см. `VHWideRangeScan.md`) — это ограничение уровня скана,
  а не отпечатка.
