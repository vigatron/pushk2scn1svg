# VHSHA256

## Файл / Модуль

- Заголовок: `src/mods/vhsha256/VHSHA256.hpp`
- Реализация: `src/mods/vhsha256/VHSHA256.cpp`
- Класс: `class VHSHA256`

## Назначение

Вычисление криптографического хеша SHA-256 от массива байтов.
Используется для идентификации исходного файла: хеш попадает
в SVG-документы (подвал DNA-документа и метаданные WND-документа)
и позволяет сверить, от какого именно файла построен документ.

## Ответственность

- Вычисление SHA-256 дайджеста (чистая реализация без внешних зависимостей).
- Преобразование дайджеста в hex-строку.
- Предоставление удобного API: `hash()` (бинарный) и `hashHex()` (строка).

## Поля / Данные

| Имя | Тип | Назначение |
|---|---|---|
| `DIGEST_SIZE` | `static constexpr size_t = 32` | Размер дайджеста SHA-256 в байтах. |
| `Digest` | `using = std::array<uint8_t, 32>` | Тип бинарного дайджеста. |
| `K[64]` (в анонимном namespace `.cpp`) | `constexpr std::array<uint32_t, 64>` | Константы SHA-256. |
| Функции `rotr/ch/maj/bsig0/bsig1/ssig0/ssig1/transform` (в анонимном namespace `.cpp`) | — | Примитивы SHA-256: повороты, функции выбора/мажоритарности, блочное преобразование. |

## Методы

| Сигнатура | Описание |
|---|---|
| `static Digest hash(const std::vector<uint8_t> &data)` | Вычисляет SHA-256: начальное состояние (8 слов), обработка полных 64-байтных блоков, дополнение (padding: `0x80`, нули, 64-битная длина в битах), финальное преобразование, сериализация состояния в 32 байта (big-endian). |
| `static std::string hashHex(const std::vector<uint8_t> &data)` | `toHex(hash(data))` — строка из 64 hex-символов (нижний регистр). |
| `static std::string toHex(const Digest &digest)` | Преобразует 32 байта в 64 hex-символа через таблицу `0123456789abcdef`. |

## Связи / Зависимости

- **Входящие:** `VHSrcDataArray::LoadSource()` (хеш загруженного файла), далее строка хеша передаётся в `VHDocWnd::GenerateDocument` и `VHDocDNA::GenerateDocument`.
- **Исходящие:** только стандартная библиотека (`<array>`, `<cstdint>`, `<cstring>`, `<string>`, `<vector>`).

## Использование

```cpp
std::string hex = VHSHA256::hashHex(arrsrc);  // 64 символа
VHSHA256::Digest d = VHSHA256::hash(arrsrc);  // 32 байта
```

## Ограничения / Замечания

- Реализация обрабатывает весь массив в памяти сразу — для больших файлов (гигабайты) нужен потоковый вариант обновлений по чанкам. Для текущего инструмента (≤ 32 КБ по сканированию) не критично.
- Корректность padding при `rem >= 56` проверяется, дополняющий блок обнуляется через `memset`.
- Алгоритм не использует криптографических библиотек — при использовании в security-критичных местах стоит сверять с эталонными тестами (NIST).
