# BlockProps

## Файл / Модуль

- Заголовок: `src/mods/structs/blockprops.hpp`
- Реализация: полностью инлайн (метод `scan()` в заголовке)
- Класс: `class BlockProps`

## Назначение

Структура-дескриптор одного блока данных (окна фиксированного размера):
хранит статистику распределения значений байтов внутри блока
(минимум, максимум, количество уникальных значений и гистограмму).
Используется генератором WND-документа для отрисовки секций и плотности.

## Ответственность

- Сканирование блока байтов (`scan`) и вычисление статистики.
- Хранение гистограммы распределения значений 0..255.

## Поля / Данные

| Поле | Тип | Назначение |
|---|---|---|
| `_min` | `uint8_t` | Минимальное значение байта в блоке. |
| `_max` | `uint8_t` | Максимальное значение байта в блоке. |
| `spc[256]` | `uint8_t[256]` | Гистограмма: количество вхождений каждого значения (насыщение на 255). |
| `wght` | `uint8_t` | Количество уникальных значений в блоке (ширина распределения). |

## Методы

| Сигнатура | Описание |
|---|---|
| `BlockProps()` | Пустой конструктор. |
| `void scan(const uint8_t *ptr, int subsize)` | Проходит `subsize` байтов от `ptr`: обновляет `min`/`max`, заполняет `spc[]` (до 255 на значение), затем считает `wght` — количество ненулевых элементов `spc`. |

## Связи / Зависимости

- **Входящие:** `VHDocWnd::GenSamplesArray()` создаёт вектор `BlockProps` для каждого размера чанка; поля читаются в `draw/draw_section.cpp`, `draw/draw_density.cpp` и функции `DumpSamples()` (`global/global.cpp`).
- **Исходящие:** `vhplatform.hpp` (для `memset`/`uint8_t`).

## Использование

```cpp
BlockProps blk;
blk.scan(arrsrc.data() + i * subsize, static_cast<int>(subsize));
// blk._min, blk._max, blk.wght, blk.spc[]
```

## Ограничения / Замечания

- Поля `_min`, `_max`, `wght`, `spc` **не инициализируются** конструктором — корректны только после вызова `scan()`.
- `wght` — `uint8_t`, но максимальное количество уникальных значений 256: при блоке со всеми 256 значениями счётчик упрётся в защиту `wght < 255`.
- `scan` не проверяет `ptr == nullptr` и `subsize <= 0`.
