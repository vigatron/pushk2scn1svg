# Правила для ИИ агентов


1. Папка `src/extmods` - только для чтения ! Это папка submodules - нельзя трогать и редактировать.

2. Папка `rules` — содержит описания классов проекта в формате .md (индекс — `rules/README.md`, далее по одному файлу на класс, например `rules/VHAppCore.md`). Это предназначение папки: здесь фиксируются требования к классам — назначение, ответственность, поля, методы, связи.

3. Файлы в папке `rules` являются источником требований к функционалу классов. При любой работе с классом сначала читай его описание в `rules/`, а реализованный функционал должен соответствовать этому описанию. Если описание расходится с кодом — приведи код в соответствие с `rules/` (или явно укажи на расхождение, если код должен оставаться источником истины).

4. Требования, функции и правки будут обновляться прямо в файлах папки `rules`. После изменения требований в `rules/` код должен быть обновлён в соответствии с ними в рамках той же задачи.

5. Каждый класс (его `.hpp` и `.cpp`) должен находиться в своей собственной папке `src/mods/<classname>`, где `<classname>` — имя класса в нижнем регистре (например, класс `VHAppCore` — в `src/mods/vhappcore/vhappcore.hpp` и `src/mods/vhappcore/vhappcore.cpp`, класс `VHAppCoreCfg` — в `src/mods/vhappcorecfg/`). При создании нового класса и при касании существующего класса в задаче — размещай/перемещай файлы по этому правилу и обновляй подключения (includes, `CMakeLists.txt`, описания в `rules/`).

6. Максимально допустимый размер файла для обработки ограничен 32 КБ (32 768 байт) ! (uint16_t)
